Cadastro de Clientes - CI/CD

Projeto simples em HTML, CSS e JavaScript desenvolvido para demonstrar
um processo de integração e entrega contínua.

Pipeline:
Código-fonte → Testes Unitários → GitHub Actions → Docker Hub → AWS EC2

Tecnologias:
- HTML
- CSS
- JavaScript
- Node.js Test Runner
- Docker
- Nginx Alpine
- GitHub Actions
- Docker Hub
- Amazon EC2
